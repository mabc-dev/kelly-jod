About This App

Kelly Jod was built for MABC Roastco to track full income and expenses, with a calendar, budgets, tags, and analytics. Data syncs live across devices via a shared database — everyone using the app sees the same up-to-date numbers. The PIN is a convenience lock, not strong security; don't use this for anything beyond small-team bookkeeping.
